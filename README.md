# Team Hauchdev Documentation

Official documentation site for [hLobby](https://github.com/hauchdev/hLobby) and [hChat](https://github.com/hauchdev/hChat), built with [Mintlify](https://mintlify.com).

## Live site

Visit the published documentation at `https://docs.hauchdev.com` (update this URL after deploying).

## Local development

Install the Mintlify CLI:

```bash
npm i -g mint
```

Run the development server:

```bash
mint dev
```

Open `http://localhost:3000` to preview your changes.

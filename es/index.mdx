Bienvenido a la documentación oficial de **Team Hauchdev**. Aquí encontrarás todo lo necesario para instalar, configurar, ampliar y contribuir a nuestros plugins de Minecraft.

<CardGroup cols={2}>
  <Card title="hLobby" icon="server" href="/es/hLobby">
    Gestión moderna de lobbies para proxies Velocity. Enrutamiento inteligente, cuenta atrás de teletransporte, redirección de expulsiones, soporte multilingüe y API pública.
  </Card>
  <Card title="hChat" icon="messages" href="/es/hChat">

  </Card>

## Qué puedes hacer aquí

- **Empezar rápido** con guías de instalación paso a paso.
- **Configurar cada función** con referencias completas y ejemplos.
- **Integrar** con PlaceholderAPI, DiscordSRV, Velocity, LuckPerms y Vault.
- **Construir encima** de nuestras APIs públicas para hLobby y hChat.
- **Contribuir** con código, traducciones, reportes de errores o ideas.

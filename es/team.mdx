# Team Hauchdev

Team Hauchdev es el creador de **hLobby** y **hChat**, plugins de Minecraft de código abierto construidos para dueños de servidores y desarrolladores.

## Proyectos

| Proyecto | Descripción | Repositorio |
| --- | --- | --- |
| hLobby | Gestión moderna de lobbies para proxies Velocity. | [github.com/hauchdev/hLobby](https://github.com/hauchdev/hLobby) |
| hChat | Sistema de chat completo para servidores Paper 1.20+. | [github.com/hauchdev/hChat](https://github.com/hauchdev/hChat) |

## Líder

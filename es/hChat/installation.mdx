## Descarga

Descarga el JAR más reciente desde la [página de releases](https://github.com/hauchdev/hChat/releases/latest) o desde [Modrinth](https://modrinth.com/plugin/hchat).

```bash
wget https://github.com/hauchdev/hChat/releases/latest/download/hChat.jar
```

## Instalación

<Steps>
  <Step title="Coloca el jar" icon="folder-open">
    Mueve el JAR descargado a la carpeta `plugins/` de tu servidor.

    ```bash
    mv hChat.jar /ruta/al/servidor/plugins/
    ```
  </Step>
  <Step title="Instala dependencias" icon="puzzle-piece">
    Asegúrate de que PlaceholderAPI esté instalado. LuckPerms es recomendado para gestionar permisos.
  </Step>
  <Step title="Inicia el servidor" icon="play">
    Inicia o reinicia tu servidor. hChat creará `plugins/hChat/config.yml` y `plugins/hChat/lang/lang_en.yml` en el primer inicio.
  </Step>
  <Step title="Configura" icon="sliders">
    Edita `config.yml` para que se ajuste a tu servidor, luego ejecuta `/hchat reload`.
  </Step>
</Steps>

## Verifica la instalación

Ejecuta `/hchat about` en el juego o `hchat about` desde la consola. Deberías ver la versión del plugin, autores y resumen de funciones.

## Actualizar

Para actualizar hChat:

1. Detén tu servidor.
2. Reemplaza el JAR antiguo por el nuevo en `plugins/`.
3. Vuelve a iniciar el servidor.

Tus archivos de configuración e idioma se conservan. Las nuevas opciones se añaden automáticamente si faltan.

# hChat

**hChat** es un sistema de chat moderno y completo para servidores [Paper](https://papermc.io) 1.20+. Incluye canales de chat, mensajes privados, menciones, herramientas de moderación, filtros, AFK, correo, repetición de chat, integración con PlaceholderAPI y más.

## Características

| Característica | Descripción |
| --- | --- |
| Mensajes privados | Formato personalizable con tooltips y clic para responder. |
| @Menciones | Sonido configurable, color de resaltado y notificación personal. |
| Modo espía | Monitoriza mensajes privados con un permiso dedicado. |
| Sistema de ignore | Lista de bloqueo persistente por jugador. |
| Multiidioma | Localización YAML con selección de idioma por jugador. |
| PlaceholderAPI | `%hchat_spy_enabled%`, `%hchat_ignored%`, DND, última vez visto, etc. |
| MiniMessage + hex | Etiquetas MiniMessage, hex `&#RRGGBB` y códigos `&` clásicos. |
| Hover y clic | Tooltips y acciones clicables en cada línea de chat. |
| Anuncios | `/bc` manual más programador de anuncios automáticos. |
| Moderación | Slowmode, bloqueo de chat y chat de staff (`/sc`). |
| Cadena de filtros | Filtro de palabras, anti-mayúsculas, anti-unicode, anti-publicidad y anti-spam. |
| Registro de chat | Logs diarios rotativos con retención configurable. |
| Canales de chat | Por mundo, por permiso, alias y enfriamientos. |
| Correo | Mensajes offline con `/hchat mail read\|clear\|send`. |
| AFK | Detección automática de inactividad más `/afk [mensaje]`. |
| Menciones masivas | `@everyone` / `@here` con enfriamiento y sonido. |
| Ping y visto | `/ping [jugador]` y `/seen <jugador>`. |
| Repetición de chat | `/hchat replay [jugador]` en un buffer circular. |

## Requisitos

- Un servidor [Paper](https://papermc.io) 1.20+.
- Java 21 o superior.
- [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) 2.11+.
- [LuckPerms](https://luckperms.net) (recomendado pero ya no obligatorio).

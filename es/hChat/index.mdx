# hChat

**hChat** es un sistema de chat moderno y completo para servidores [Paper](https://papermc.io) 1.20+. Incluye canales de chat, mensajes privados, menciones, herramientas de moderación, filtros, AFK, correo, repetición de chat, integración con PlaceholderAPI y más.

## Características

<CardGroup cols={3}>
  <Card title="Mensajes privados" icon="envelope">
    Formato personalizable con tooltips y clic para responder.
  </Card>
  <Card title="@Menciones" icon="at">
    Sonido configurable, color de resaltado y notificación personal.
  </Card>
  <Card title="Modo espía" icon="eye">
    Monitoriza mensajes privados con un permiso dedicado.
  </Card>
  <Card title="Sistema de ignore" icon="user-slash">
    Lista de bloqueo persistente por jugador.
  </Card>
  <Card title="Multiidioma" icon="language">
    Localización YAML con selección de idioma por jugador.
  </Card>
  <Card title="PlaceholderAPI" icon="puzzle-piece">
    `%hchat_spy_enabled%`, `%hchat_ignored%`, DND, última vez visto, etc.
  </Card>
  <Card title="MiniMessage + hex" icon="palette">
    Etiquetas MiniMessage, hex `&#RRGGBB` y códigos `&` clásicos.
  </Card>
  <Card title="Hover y clic" icon="computer-mouse">
    Tooltips y acciones clicables en cada línea de chat.
  </Card>
  <Card title="Anuncios" icon="bullhorn">
    `/bc` manual más programador de anuncios automáticos.
  </Card>
  <Card title="Moderación" icon="shield-halved">
    Slowmode, bloqueo de chat y chat de staff (`/sc`).
  </Card>
  <Card title="Cadena de filtros" icon="filter">
    Filtro de palabras, anti-mayúsculas, anti-unicode, anti-publicidad y anti-spam.
  </Card>
  <Card title="Registro de chat" icon="file-lines">
    Logs diarios rotativos con retención configurable.
  </Card>
  <Card title="Canales de chat" icon="tower-broadcast">
    Por mundo, por permiso, alias y enfriamientos.
  </Card>
  <Card title="Correo" icon="paper-plane">
    Mensajes offline con `/hchat mail read\|clear\|send`.
  </Card>
  <Card title="AFK" icon="bed">
    Detección automática de inactividad más `/afk [mensaje]`.
  </Card>
  <Card title="Menciones masivas" icon="users">
    `@everyone` / `@here` con enfriamiento y sonido.
  </Card>
  <Card title="Ping y visto" icon="clock">
    `/ping [jugador]` y `/seen <jugador>`.
  </Card>
  <Card title="Repetición de chat" icon="rotate-left">
    `/hchat replay [jugador]` en un buffer circular.
  </Card>
</CardGroup>

# hLobby

**hLobby** es un sistema de lobbies altamente configurable para [Velocity](https://papermc.io/software/velocity) 3.4.0+. Ofrece enrutamiento inteligente, cuenta atrás de teletransporte, redirección de expulsiones, mensajes multilingües y una API pública pequeña.

## Características

<CardGroup cols={3}>
  <Card title="Enrutamiento inteligente" icon="route">
    Estrategias aleatoria, menos/más jugadores, primero disponible, prioridad y round-robin.
  </Card>
  <Card title="Cuenta atrás" icon="hourglass-half">
    Retraso configurable con cancelación al moverse, chatear y permiso de omisión.
  </Card>
  <Card title="Enfriamientos" icon="stopwatch">
    Enfriamiento por jugador para `/lobby` y evitar spam.
  </Card>
  <Card title="Redirección al entrar y al expulsar" icon="arrow-right-arrow-left">
    Envía a los jugadores a un lobby al conectarse o tras ser expulsados.
  </Card>
  <Card title="Servidores bloqueados" icon="ban">
    Desactiva `/lobby` en servidores específicos.
  </Card>
  <Card title="Servidor de respaldo" icon="life-ring">
    Une a un servidor de respaldo cuando no haya lobbies.
  </Card>
  <Card title="Mensajes de entrada" icon="message">
    Título, action bar y mensaje de chat al entrar a un lobby.
  </Card>
  <Card title="Personalización de comandos" icon="keyboard">
    Renombra, crea alias o desactiva cada comando desde config.
  </Card>
  <Card title="Multiidioma" icon="language">
    Inglés y español incluidos; fácil añadir más.
  </Card>
  <Card title="Métricas FastStats" icon="chart-simple">
    Estadísticas de uso anónimas con opción de desactivar.
  </Card>
  <Card title="Comprobador de actualizaciones" icon="rotate">
    Notifica a los operadores cuando hay una nueva versión.
  </Card>
  <Card title="API pública" icon="plug">
    API pequeña y estable para plugins de terceros.
  </Card>
</CardGroup>

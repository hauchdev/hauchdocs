# hChat

**hChat** is a modern and complete chat system for [Paper](https://papermc.io) 1.20+ servers. It includes chat channels, direct messages, mentions, moderation tools, filters, AFK, mail, chat replay, PlaceholderAPI integration, and more.

## Features

<CardGroup cols={3}>
  <Card title="Direct messages" icon="envelope">
    Customizable format with hover tooltips and click-to-reply.
  </Card>
  <Card title="@Mentions" icon="at">
    Configurable sound, highlight color, and personal notification.
  </Card>
  <Card title="Spy mode" icon="eye">
    Monitor private messages with a dedicated permission.
  </Card>
  <Card title="Ignore system" icon="user-slash">
    Persistent per-player block list that survives reloads.
  </Card>
  <Card title="Multi-language" icon="language">
    YAML localization with per-player language selection.
  </Card>
  <Card title="PlaceholderAPI" icon="puzzle-piece">
    `%hchat_spy_enabled%`, `%hchat_ignored%`, DND, last seen, and more.
  </Card>
  <Card title="MiniMessage + hex" icon="palette">
    MiniMessage tags, `&#RRGGBB` hex, and classic `&` codes.
  </Card>
  <Card title="Hover & click" icon="computer-mouse">
    Tooltips and clickable actions on every chat line.
  </Card>
  <Card title="Broadcasts" icon="bullhorn">
    Manual `/bc` plus auto-broadcast scheduler.
  </Card>
  <Card title="Moderation" icon="shield-halved">
    Slowmode, chat lock, and staff chat (`/sc`).
  </Card>
  <Card title="Filter chain" icon="filter">
    Word filter, anti-caps, anti-unicode, anti-ad, and anti-spam.
  </Card>
  <Card title="Chat logger" icon="file-lines">
    Rotating daily logs with configurable retention.
  </Card>
  <Card title="Chat channels" icon="tower-broadcast">
    Per-world, per-permission, aliases, cooldowns.
  </Card>
  <Card title="Mail" icon="paper-plane">
    Offline messages with `/hchat mail read\|clear\|send`.
  </Card>
  <Card title="AFK" icon="bed">
    Automatic inactivity detection plus `/afk [message]`.
  </Card>
  <Card title="Mass mentions" icon="users">
    `@everyone` / `@here` with cooldown and sound.
  </Card>
  <Card title="Ping & seen" icon="clock">
    `/ping [player]` and `/seen <player>`.
  </Card>
  <Card title="Chat replay" icon="rotate-left">
    `/hchat replay [player]` on a ring buffer.
  </Card>
</CardGroup>

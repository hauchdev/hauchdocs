## Prerequisites

<CardGroup cols={3}>
  <Card title="Paper 1.20+" icon="cube">
    A running Paper server.
  </Card>
  <Card title="Java 21+" icon="mug-hot">
    Required runtime version.
  </Card>
  <Card title="PlaceholderAPI 2.11+" icon="puzzle-piece">
    Must be installed.
  </Card>
</CardGroup>

<Tip>
  [LuckPerms](https://luckperms.net) is recommended for permission management.
</Tip>

## Download

Download the latest JAR from the [releases page](https://github.com/hauchdev/hChat/releases/latest) or from [Modrinth](https://modrinth.com/plugin/hchat).

```bash
wget https://github.com/hauchdev/hChat/releases/latest/download/hChat.jar
```

## Install

<Steps>
  <Step title="Place the jar" icon="folder-open">
    Move the downloaded JAR into your server's `plugins/` folder.

    ```bash
    mv hChat.jar /path/to/server/plugins/
    ```
  </Step>
  <Step title="Install dependencies" icon="puzzle-piece">
    Make sure PlaceholderAPI is installed. LuckPerms is recommended for permission management.
  </Step>
  <Step title="Start the server" icon="play">
    Start or restart your server. hChat will create `plugins/hChat/config.yml` and `plugins/hChat/lang/lang_en.yml` on first start.
  </Step>
  <Step title="Configure" icon="sliders">
    Edit `config.yml` to match your server setup, then run `/hchat reload`.
  </Step>
</Steps>

## Verify the installation

Run `/hchat about` in-game or `hchat about` from the console. You should see the plugin version, authors, and feature overview.

## Updating

To update hChat:

1. Stop your server.
2. Replace the old JAR with the new one in `plugins/`.
3. Start the server again.

Your config and language files are preserved. New options are added automatically when missing.

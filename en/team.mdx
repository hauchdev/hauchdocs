# Team Hauchdev

Team Hauchdev is the creator of **hLobby** and **hChat**, open-source Minecraft plugins built for server owners and developers.

## Projects

| Project | Description | Repository |
| --- | --- | --- |
| hLobby | Modern lobby management for Velocity proxies. | [github.com/hauchdev/hLobby](https://github.com/hauchdev/hLobby) |
| hChat | Complete chat system for Paper 1.20+ servers. | [github.com/hauchdev/hChat](https://github.com/hauchdev/hChat) |

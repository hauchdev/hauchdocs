# hLobby

**hLobby** is a highly configurable, proxy-side lobby system for [Velocity](https://papermc.io/software/velocity) 3.4.0+. It provides smart routing, teleport countdowns, kick redirection, multi-language messages, and a small public API.

## Features

<CardGroup cols={3}>
  <Card title="Smart routing" icon="route">
    Random, least/most players, first available, priority, and round-robin strategies.
  </Card>
  <Card title="Teleport countdown" icon="hourglass-half">
    Configurable delay with cancel-on-move, cancel-on-chat, and bypass permission.
  </Card>
  <Card title="Cooldowns" icon="stopwatch">
    Per-player `/lobby` cooldown to stop spam.
  </Card>
  <Card title="Join & kick redirect" icon="arrow-right-arrow-left">
    Send players to a lobby on connect or after a kick.
  </Card>
  <Card title="Blocked servers" icon="ban">
    Disable `/lobby` on specific downstream servers.
  </Card>
  <Card title="Fallback server" icon="life-ring">
    Join a backup server when no lobby is available.
  </Card>
  <Card title="Join messages" icon="message">
    Title, action bar, and chat greeting on lobby join.
  </Card>
  <Card title="Command customization" icon="keyboard">
    Rename, alias, or disable every command from config.
  </Card>
  <Card title="Multi-language" icon="language">
    English and Spanish included; easy to add more.
  </Card>
  <Card title="FastStats metrics" icon="chart-simple">
    Anonymous usage statistics with opt-out in config.
  </Card>
  <Card title="Update checker" icon="rotate">
    Notifies operators when a new release is available.
  </Card>
  <Card title="Public API" icon="plug">
    Small, stable API for third-party plugins.
  </Card>
</CardGroup>
